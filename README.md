This capstone project explores network traffic analysis using Random Forest and XGBoost machine learning algorithms, with the goal of identifying devices and operating systems present on a network through passive analysis of packet captures. Raw network traffic will be converted into usable machine learning inputs using nPrint, which transforms packets into a unified structure. This approach builds on techniques used in network intrusion detection, where packet features can be used to classify traffic as malicious or benign. We will then utilize SHAP (SHapley Additive exPlanations), a method for explaining machine learning model outputs, to determine how much each input feature contributes to a specific prediction.
